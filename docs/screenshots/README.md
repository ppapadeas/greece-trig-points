# Screenshots

Place the project's hero screenshot at `map-with-tags.png` in this directory.
The README references it at `docs/screenshots/map-with-tags.png`.

Suggested capture:

- 1440 × 900 viewport at https://vathra.xyz
- Filter capsule visible in top-right with at least one filter active
- A point with the warning glyph visible on the map
- Sidebar open on a point that has at least one warning tag and a few non-warning tags

PNG, < 500 KB. Optimize with `pngquant` or `oxipng` before committing.
